\begin{abstract}
本文针对多核神经网络处理器（NPU）上的 AI 计算图调度问题，建立了黑箱评估器驱动的 DAG 划分与自适应变邻域搜索模型，目标是最小化官方评估器给出的字典序指标 $(Makespan, AddedCopy)$。

\textbf{建模思路}：将多核调度分解为图划分、核分配和子图排序三个耦合决策，通过四族多粒度初解策略生成结构互补的初始方案，再以自适应变邻域搜索（VNS）进行局部优化，在固定评估预算约束下最大化搜索效率。

\textbf{主要方法}：（1）提出负载均衡、亲和度感知、关键路径优先和管道平衡四族种子策略，配合 grain=4/12/32 三层粒度和 fine\_grain=2 细粒度变体，覆盖不同类型 DAG 的计算与通信特征。（2）实现八类邻域结构（核移动、核间交换、独立块换序、块合并、块分裂、边界调整、强连接联合放置、关键路径移动），以粗粒度完成时间和通信量作为代理代价进行候选排序，仅将 top-2 最有价值候选提交昂贵的官方评估，使每轮约 80\% 的低价值候选被提前过滤。（3）引入自适应邻域预算分配机制，基于历史 gain\_per\_eval 和 gain\_per\_second 动态调整各邻域的搜索资源，对零收益邻域自动去活以节省预算。（4）在 Portfolio 中恢复 grain=2 细粒度粗化变体，修正 development\_v1 到 v2 在特定算例上的算法回退。

\textbf{结果与结论}：在 100 个官方算例（766∼38,666 操作节点，DAG 深度 2∼459 层）上完成了结构审计与求解。6 例固定开发集上的消融实验表明：自适应 VNS 结合细粒度种子恢复（A2 配置）相对基线平均 Makespan 降低 17.74\%，10/24 组严格改善，12/24 组持平。关键回归 case\_019（P1/N2）从 +10.66\% 修正至 −0.47\%。自适应预算使收益集中于 N1（50 次改善/236 次评估）和 N2（23/128），将 N3 从强制分配转为低概率探索，测试中 N3 的 78 次评估未观察到严格改善。相对独立官方单核基准，P1/P2 在 N=4 下的平均加速比达到 2.42 和 2.89。49 项确定性测试全部通过，本文提供的所有结果可严格复现。

\textbf{创新点}：（1）在黑箱评估场景下提出 candidate-based VNS 框架，以代理代价排序替代直接逐候选调用评估器；（2）设计自适应邻域预算机制，使搜索资源向高效邻域集中，避免在无效邻域浪费有限预算；（3）提出 grain=2 细粒度种子变体作为通用 portfolio 候选，在不针对特定算例的前提下解决算法回归。

\keywords{多核调度\quad DAG 划分\quad 变邻域搜索\quad 神经网络处理器\quad 黑箱优化}
\end{abstract}

\section{问题重述}

\subsection{问题背景}

随着深度学习模型在智能手机、自动驾驶和物联网终端上的广泛部署，多核神经网络处理器（NPU）已成为端侧 AI 推理的核心硬件平台~\cite{jouppi2017}。典型的 NPU 架构包含 $N$ 个同构计算核心，每个核心配备私有的 L1 缓存（524,288 bytes）和统一缓冲区 UB（131,072 bytes），核心间共享 DDR 主存，DDR 带宽为 60 bytes/cycle。每个核心内部包含四条硬件流水线：PIPE\_MTE2（DDR→L1/UB）、PIPE\_MTE3（L1/UB→DDR）、PIPE\_M（Cube 计算单元）和 PIPE\_V（Vector 计算单元）。

在给定 AI 计算图（以操作-张量二部有向无环图表示）时，编译器需要将操作节点划分为子图（subgraph）、将子图分配到各核心、并确定各核心上的子图执行顺序，使得总执行时间（Makespan）最小。这一调度问题面临三个相互耦合的决策：切图改变子图规模和通信边界；核心分配决定负载均衡和跨核通信量；核内调度顺序影响依赖等待、张量驻留时间和缓存换入换出。减少切分可降低通信，却可能压缩并行度并增大缓存压力；增加切分可提供更多并行机会，却可能带来重复读取和更多 DDR 搬运。

三种硬件场景对调度器施加了不同的约束：

\subsection{问题描述}

给定计算图 $G = (T \cup O, E)$ 和核心数 $N$，其中 $T$ 为张量节点集合（存储数据块），$O$ 为操作节点集合（计算或搬运），$E \subseteq (T \times O) \cup (O \times T)$ 为有向边集合。每个操作 $o \in O$ 具有指定的执行管道（PIPE\_M、PIPE\_V、PIPE\_MTE2 或 PIPE\_MTE3）和计算周期数 $c_o$。每个张量 $t \in T$ 具有逻辑存储位置（DDR、L1 或 UB）和数据大小 $s_t$。COPY\_IN 和 COPY\_OUT 分别负责 DDR 与核内缓存之间的数据搬运。

官方评估器在收到选手提交的切分方案（node\_to\_subgraph 和 core\_schedules）后，内部执行完整的核内调度流程（Step1：构建扩展执行图；Step2：缓存驻留检查与换入换出；Step3：四条流水线上按依赖和资源约束排布时间线），最终返回 $(Makespan, AddedCopy)$ 字典序指标。评估器对参赛者是不可微的黑箱，单次调用耗时 0.2∼90 秒，占总求解时间的 95.7\%。

赛题包含三种硬件场景，对应三个问题：
\begin{enumerate}
  \item \textbf{场景 A（问题 1）}：每个子图构成一个独立 Task，同核 Task 切换等待 100 cycles，跨核 Task 等待 1000 cycles，所有核间数据必须经 DDR 中转。
  \item \textbf{场景 B（问题 2）}：每核所有子图合并为一个 Task，同核子图间数据可在片上直传（不产生 COPY），跨核 COPY 延迟降为 500 cycles。核心风险从“通信开销主导”转为“存储溢出主导”。
  \item \textbf{场景 B + L2 Cache（问题 3）}：在问题 2 基础上增加 1 MB、250 bytes/cycle 的只读 FIFO 共享 Cache，仅 COPY\_IN 操作查询。
\end{enumerate}

\section{模型假设与符号说明}

\subsection{模型假设}

\begin{enumerate}
  \item \textbf{评估器确定性假设}：对同一方案、同一算例和同一问题，官方评估器返回完全相同的 Makespan 与 Added Copy，不存在运行时随机波动。
  \item \textbf{操作不可分割假设}：单个操作节点不可拆分到不同子图中，必须整体归属于某个子图。
  \item \textbf{核心同构假设}：所有 $N$ 个 NPU 核心的 L1、UB 容量和计算能力完全相同。
  \item \textbf{子图分配互斥性}：每个非 COPY 操作恰好属于一个子图，每个子图恰好分配到一个核心。
  \item \textbf{内存估计不作为硬约束}：内存和 Cache 代理估计仅用于候选排序中的参考信息，不以此删除候选方案（默认权重均为 0）。
  \item \textbf{图结构预计算正确性假设}：基于官方输入 DAG 的一次性特征预计算（拓扑序、深度、关键路径秩、弱连通分量和管道工作量）对所有后续求解阶段均有效且不变。
\end{enumerate}

\section{模型建立与求解}

\subsection{算法框架总览}

本文提出的求解框架由三个阶段组成：（1）多粒度图粗化与四族初解生成——对输入 DAG 进行两层聚合，产出覆盖不同图结构特征的初始方案集合；（2）候选筛选与 top-K 评估——以粗粒度代价估计对候选方案排序，仅将最有价值的 top-2 方案提交昂贵的官方评估；（3）自适应变邻域搜索——基于历史收益动态分配预算给八类邻域，以改进当前最优方案。

算法流程图：输入 DAG → 特征预计算 → 四族多粒度种子生成 → Portfolio 初解 → Top-K 评估 → 自适应 VNS → 输出最优方案。

\subsection{图粗化与多粒度种子生成}

\subsubsection{两层粗化}

对输入 DAG $G$，先沿拓扑序扫描，将相邻的强亲和操作（共享输入张量或存在直接依赖）聚合为 \textbf{atomic runs}，再按总计算量预算（$\sum c_o \,/\, (N \times g)$）将 atomic runs 进一步合并为 \textbf{coarse blocks}。聚合过程中保持连续拓扑区间，确保商图无环。采用 $g \in \{4, 12, 32\}$ 三种标准粒度，另外提供 $g=2$ 的细粒度变体作为附加 Portfolio 候选。

\subsubsection{四族种子策略}

四种策略从不同维度产生结构互补的初始方案：

\begin{enumerate}
  \item \textbf{Load-balanced}：沿确定性的图拓扑序按累计工作量均衡切分，将段分配到当前工作量最小的核心。适合大规模宽图（如 case\_025，width=5332）实现基础负载均衡。
  \item \textbf{Affinity-aware}：基于前驱-后继传播构建局部序列，优先将共享输入或直接依赖的操作归入同一核心。在核分配时扣减同核输入复用带来的完成时间折扣，效用取决于图内的共享超边数量。
  \item \textbf{Critical-path}：以上行+下行关键路径秩驱动优先级排序，Ready-list 中总是优先秩最大者并分配到最早可用核心。适合深链 DAG（如 case\_047，depth=459）。对 Transformer 类型的赘余依赖也具有显著的收益。
  \item \textbf{Pipe-balanced}：在 Critical-path 基础上带入双管道（PIPE\_M + PIPE\_V）的累积工作比。划定等量段时确保组内 M/V 配比均衡，防止集中在单一流水线引发硬件饥饿，对于 PIPE\_M/$\Sigma$cycles $\geq 30\%$ 的算子群高度优先。
\end{enumerate}

在全部 op 数 $\leq 10,000$ 的算例上增加一“整图单核”候选。这首先源于现实：过度切分（尤其深度很大的链式 DAG）会制造远超跨核惩罚开销的通信量，保留全局的单核对照可作极端兜底。

\subsubsection{核分配}

初解锁定子图顺序后，核心分配采用简化的 HEFT 风格预估值：每个子图的预估开始时间为 `max（前驱结束时间 + inter-core communication 惩罚）`，以最小评估值分配到最早可用核心，同时核内复用进行 discount。

\subsubsection{候选筛选与 top-K 评估}

每一轮 VNS 最多产生 $\leq 24$ 个去重候选。以粗粒度完成时间估计、通信量估计和管道工作量平衡度—— 代理模型中均置 $\textit{memory\_weight=0, cache\_weight=0}$—— 对候选排序后，仅 top-2 提交昂贵的官方评估器验证。达到 80\% 的便宜过滤率，在最大 36 次真实评估的预算内极大提升单位评估带来的 Make 收益。\cite{shahriari2016}

\subsubsection{自适应预算分配}

基于 eight 邻域积累的 \texttt{attempts/successes/gain/evaluation\_time} 统计。每完成一轮后，计算两类排名分数：

\[
\text{gain\_per\_eval}(k)=\frac{\text{total gain in }\mathcal{N}_k}{\text{evaluations in }\mathcal{N}_k},\qquad
\text{gain\_per\_sec}(k)=\frac{\text{total gain in }\mathcal{N}_k}{\text{evaluator time in }\mathcal{N}_k}.
\]

决策轮以 gain\_per\_eval 排名优先分配搜索 budget；同时以 20\% 均匀探索防止过早坍缩于有限邻域。当某个邻域评估次数超过最低门槛（min\_neighbourhood\_trials=3）且累积收益仍然为零时，邻域被去活。这一机制无需为不同算例人工设定搜索策略，也无需求解 external 优化问题来决定 budget 划分。\cite{mladenovic1997,hansen2001}

\subsubsection{搜索预算与早停}

单次求解的硬约束包括：(1) \texttt{max\_evaluations} = 36 次官方评估，(2) \texttt{time\_budget} = 120 秒的软截止（两次评估调用之间检查，不中断正在进行中的的评估），(3) 图规模 > 10,000 ops 时额外限制最大评估量 20–26 次。同时引入 \texttt{stagnation\_patience=8}：若连续 8 次评估未产生改善即提前终止搜索。

\subsection{细粒度 Portfolio 种子恢复}

development\_v1 采用了 grain=2 的 pipe-4 粗化行为，产生更细的划分细度；development\_v2 切换到 grain=4/12/32 后丢失这一选择，导致 case\_019 出现系统性回退（P1/N2 从 40,506 升至 44,825，+10.66\%）。本方案在 portfolio 中将 grain=2 变体插入为附加候选（不替换优先种子），让 VNS 在后续 N1/N4 等邻域中利用 fine-grain 进行更灵活的负载重排，同时保留标准 grain 对宽/中规模算例的效能。

\section{模型评价与结论}

\subsection{模型优点}

\begin{enumerate}
  \item \textbf{完整性}：四族种子覆盖负载、亲和度、关键路径和管道平衡四大特征轴，任一算例至少有一种策略能提供合理的初始解。
  \item \textbf{评估效率}：top-K 过滤 + 粗粒度代理代价组合将约 80\% 的候选过滤，确保有限评估预算集中于最有价值的方案。
  \item \textbf{自适应性}：邻域预算根据历史 gain\_per\_eval 和 gain\_per\_second 自动分配，无需为不同算例人工调节搜索参数。
  \item \textbf{通用性}：VNS 框架仅依赖黑箱评估器反馈，不假设内部缓存、Spill 或通信模式，可平行用于 NPU 以外的黑箱组合问题。
  \item \textbf{复现性}：确定种子、固定 coarsening 与确定性随机算法保证在同输入、同配置下结果可以被严格复制。
\end{enumerate}

\subsection{模型局限性}

\begin{enumerate}
  \item \textbf{评估器黑箱限制}：官方内部的内存 Spill、Cache FIFO 替换和带宽竞争无法被代理模型精确模拟，代理代价与实际评估之间存在系统性误差。
  \item \textbf{L2 Cache 收益有限}：在本文测试条件下，同一方案在 P3 上的 L2 加速比仅为 1.00007∼1.004，其增益远不足以改变最优方案的 pairwise 排序。
  \item \textbf{邻域覆盖不完整}：N7 和 N8 在本次统计中样本过少，其潜在价值缺乏实证支持；N3 的劣性也可能是当前 formulation 下的相对现象。
  \item \textbf{搜索空间边界}：Grain 被限定为集合 $\{2,4,12,32\}$ 而非连续变量；超参选择（budget、patience、T\_top-K）基于当前的最佳实践经验而未经系统的完全 parameter study。
  \item \textbf{预算敏感性}：全部对比均在 time=120 s / max\_evaluations=36 条件下进行，不同预算下 VNS 的收敛品质与其他元启发式策略的交叉排名仍需后续校准。
\end{enumerate}

\subsection{结论}

本文建立了面向黑箱 NPU 评估器的 DAG 划分与自适应 VNS 调度框架。通过四族多粒度种子策略、八类 VNS 邻域、top-K 候选筛选和自适应预算分配，在开发集 6 例的三轮消融实验中证明了自适应搜索和细粒度种子恢复的共同有效性——A2 最终方案在 10/24 组产生严格改善（41.7\%），同时将 case\_019 的 $+$10.66\% 关键回归修正为 $-$0.47\%。所有实验结果在固定 seed 和相同预算下可被严格复现。

该框架直接适用于任意 $N$ 核、任意预算，并为后续引入 CP-SAT 精确校验、更精细代理模型以及动态在线调度提供架构基础。
