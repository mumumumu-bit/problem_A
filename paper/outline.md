### 第三章 算法设计（约 3000 字）

**核心论点**：四族多粒度初解 + candidate-based 自适应 VNS 构成完整的求解框架。

#### 3.1 算法框架总览
- 三阶段流水线：初解生成 → candidate 候选 → VNS 局部搜索
- 算法流程图

#### 3.2 图粗化与初解生成

**3.2.1 两层粗化**
- atomic runs（拓扑序连续高亲和度算子聚合）
- coarse blocks（工作量预算控制）
- 三层粒度参数：grain ∈ {4, 12, 32} + fine_grain=2

**3.2.2 四族种子策略**
- Load-balanced：等工作量拓扑序分块
- Affinity：前驱优先 + 同核输入复用
- Critical-path：上行关键路径秩排序
- Pipe-balanced：双 Pipe 工作量均衡

**3.2.3 核分配**
- ready-list 调度 + 考虑前驱可用时间和跨核通信
- HEFT 风格的任务优先级计算

#### 3.3 自适应变邻域搜索

**3.3.1 八类邻域定义**
| 邻域 | 操作 | 物理意义 |
|------|------|----------|
| N1 核移动 | 单 block 搬移到其他核心 | 负载再均衡 |
| N2 核间交换 | 交换两个 block 的核心 | 通信优化 |
| N3 独立块换序 | 相邻独立 block 调序 | 减少任务切换 |
| N4 块合并 | 合并相邻 block | 减少跨核通信 |
| N5 块分裂 | 按工作量二分重 block | 负载均衡 |
| N6 边界调整 | 移动 block 边界操作 | 微调 |
| N7 强连接联合 | 强连通块同核放置 | 通信局部性 |
| N8 关键路径移动 | 优先关键路径内操作 | 延迟缩短 |

**3.3.2 candidate 筛选与 top-K 评估**
- 便宜估计器（粗粒度完成时间 + 通信量 + pipe 工作量）
- 排序取 top-K 提交官方评估
- 节省 80% 以上的评估调用

**3.3.3 自适应预算分配**
- 历史统计：attempts / successes / gain / evaluation_time
- 实时排序指标：gain_per_eval / gain_per_second
- 最低探索保留 + 零收益邻域去活

#### 3.4 预算管理与早停

- 软截止时间预算（120 秒）
- 最大评估次数（36 次）
- stagnation_patience 早停（8 次无改善）
- 大图特殊限制（>10,000 ops）
