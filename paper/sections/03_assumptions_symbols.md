# 3 模型假设与符号说明

## 3.1 模型假设

为建立统一的图划分与调度表示，本文仅采用以下必要抽象：

1. 对每个测试实例，输入经正式校验后可表示为有向无环计算图；节点计算周期、流水线类型及依赖边携带的数据量，均由该实例输入及其依赖恢复结果给定。
2. 对同一测试实例的一次方案评价，计算核数、硬件参数及场景配置固定；不同问题场景的执行语义由对应官方 Evaluator 确定。
3. 本文不另行构造官方 Task、等待、COPY、内存或 Cache 执行过程的替代模型；方案的正式可行性与评价指标以对应官方 Evaluator 返回结果为准。

以上是用于表述输入和评价边界的抽象，不预先规定图划分、核映射、核内顺序或 Cache 命中结果，也不排除求解器需要优化的决策。

### 赛题/硬件规则（非模型假设）

问题一、问题二、问题三各自的 Task 构造和通信规则，以及问题三只读 FIFO Cache 的访问与淘汰规则，均属于对应官方执行/评价规则，而非本文额外作出的模型假设。第4章按官方规则描述并调用 Evaluator。
