## 一、赛题分析与问题拆解

### 角色设定

你现在是一名具有丰富研究生数学建模竞赛指导经验的数学建模导师，负责帮助我分析研究生数学建模竞赛赛题。

请不要立即建立模型或给出解答，首先从数学建模角度理解赛题，明确问题背景、研究目标和核心难点，为后续建模方案设计提供依据。

请阅读我上传的赛题文件（包括题目 PDF、附件说明、数据文件等），完成以下分析。

### 1. 赛题背景分析

分析问题来源及实际场景、需要解决的核心问题、数学建模任务以及实际应用意义。

输出格式：
- **【问题背景】** 分析赛题涉及的现实场景、问题来源以及研究对象。
- **【现实意义】** 说明该问题在实际应用中的价值，以及解决该问题可能带来的影响。
- **【数学建模目标】** 明确需要通过数学方法刻画、分析和解决的核心任务。

### 2. 问题拆解

请逐个分析每个小问，明确每个问题的目标、已知条件、求解内容、数学本质以及主要挑战。

输出格式：
- **【问题 X 分析】**
  - 问题目标：说明该小问需要解决的具体问题，以及在整体赛题中的作用。
  - 已知信息：整理题目提供的数据、条件、参数和约束。
  - 求解目标：明确最终需要得到的结果或需要建立的评价指标。
  - 数学本质：判断该问题属于哪类数学问题，例如预测、优化、评价、分类、决策、模拟等。
  - 主要难点：分析该问题在数据、方法、模型或计算方面的关键挑战。

### 3. 小问逻辑关系分析

分析各小问之间的关联关系，包括是否存在数据共享、结果传递、递进关系，以及整体建模过程中的逻辑结构。

输出格式：
- **【问题链分析】** 说明各问题之间的联系和依赖关系。
- **【整体解题思路】** 概括整个赛题可能的分析路径和建模流程。

### 4. 关键变量分析

从数学建模角度提取关键变量，并按照以下形式整理：

|----------|------|

| 影响因素 | |
| 约束条件 | |

同时说明关键变量的作用，以及它们对模型结果可能产生的影响。

### 5. 初步建模方向判断

根据赛题特点，分析可能采用的建模方向。

输出格式：
- **【可能建模方向】** 列出可能适用的模型类别或研究方法。
- **【判断依据】** 结合赛题背景、数据特点和问题目标说明选择这些方向的原因。

注意：这里只分析可能方向，不确定最终模型。

### 6. 赛题难点总结

总结赛题需要重点关注的问题。

输出格式：
- **【核心问题】** 概括赛题真正需要解决的主要矛盾。
- **【关键难点】** 总结数据、模型、算法或实际应用中的困难。
- **【后续建模重点】** 指出后续模型设计时需要重点考虑的方向。

### 输出要求

1. 不直接套用固定模型，应根据赛题特点选择合适的方法。
2. 不追求复杂算法，优先考虑问题适配性和模型合理性。
3. 所有分析必须结合当前赛题内容，避免泛泛而谈。
4. 输出内容需作为后续建模方案设计和模型选择的依据。

### 角色设定

根据 Step 1 的赛题分析结果，请设计适合该问题的数学建模方案。

注意：不要直接确定最终模型，先分析多个可行方案，再为后续方案选择提供依据。

目标：寻找符合研究生数学建模竞赛要求的建模路线，重点考虑问题适配性、数学合理性、可实现性和论文表达效果。

### 4. 形成初步建模路线

根据前面的分析结果，提出建议方案。

输出：

  1. 方案选择理由；

注意：此处仅进行初步方案设计，不进行最终模型确定。

### 输出要求

1. 不为了体现高级而堆叠复杂模型，应优先选择符合问题本质的方法。
2. 所有方案必须结合当前赛题特点，避免泛泛介绍模型。
3. 综合考虑问题适配性、数学合理性、可实现性和论文表达效果。
4. 输出内容需作为下一步最终方案确定的依据。

## 四、数据分析与预处理

### 角色设定

你现在是一名数学建模竞赛数据分析专家。

根据前面确定的最终建模方案，请对赛题附件数据进行分析与处理。

目标：通过数据分析发现数据规律，验证建模可行性，并为后续数学模型建立提供依据。

请结合当前赛题背景、建模目标以及最终建模方案完成以下分析。

### 1. 数据理解

分析附件数据的基本情况，包括数据来源及作用、数据规模、数据维度、字段含义，以及输入变量、输出变量和关键影响因素。

输出：
- **【数据概况】** 说明附件数据的来源、数据规模、数据结构特点，以及数据在赛题中的作用。
- **【变量说明】**

| 字段 | 类型 | 含义 | 作用 |
|------|------|------|------|
| | | | |

### 2. 数据质量分析

检查原始数据质量，包括缺失情况、异常数据、重复数据以及数据一致性。

分析：
1. 是否需要进行数据处理；
2. 采用何种处理方法；
3. 选择该处理方法的原因；
4. 数据处理对后续模型建立的影响。

输出：
- **【数据质量分析】** 分析原始数据中可能存在的问题，以及这些问题对模型建立的影响。
- **【数据处理方案】** 说明针对数据质量问题采取的处理方法和具体原因。

### 3. 数据规律分析

根据建模目标选择合适的数据分析方法，包括描述性统计、变量关系分析、相关性分析、分布规律分析、趋势分析等。

要求说明：
1. 数据呈现出的主要规律；
2. 可能影响结果的关键因素；
3. 数据规律对后续建模的作用。

输出：
- **【数据规律分析】** 结合赛题目标分析数据特征、变量关系以及潜在规律。
- **【关键发现】** 总结对模型建立具有指导意义的重要信息。

### 4. 模型相关的数据处理

结合 Step 3 确定的建模方案，设计对应的数据处理方法。

分析是否需要进行数据标准化、特征选择、降维处理、数据变换以及样本划分。

要求说明：
1. 为什么需要该处理；
2. 该处理对模型有什么影响；
3. 如何保证数据处理服务于数学模型。

输出：
- **【数据预处理方案】** 说明数据清洗、转换、筛选等具体处理流程。
- **【模型输入设计】** 说明最终进入模型的数据形式、变量选择依据以及输入结构。

### 5. 数据与模型匹配分析

结合最终确定的模型方案，对数据适用性进行分析。

判断：
1. 当前数据是否满足模型需求；
2. 是否存在数据不足或信息缺失；
3. 后续建模需要重点关注哪些变量；
4. 需要开展哪些实验验证。

输出：
- **【数据适用性分析】** 分析当前数据与模型要求之间的匹配程度。
- **【后续建模建议】** 总结后续模型建立过程中需要重点处理的数据问题和验证方向。

### 输出要求

1. 数据分析必须结合当前赛题背景和建模目标，避免泛泛分析。
2. 不进行无目的的数据展示，每个分析方法必须说明实际作用。
3. 数据处理方案必须服务于数学模型，而不是单纯改善数据形式。
4. 输出内容需能够直接用于论文中的"数据分析与预处理"部分。

## 五、单问模型建立与求解

### 角色设定

现在开始完成 **【第 X 问】** 的数学建模与求解。

请基于前面完成的赛题分析、建模方案设计、最终建模路线以及数据分析结果，针对当前问题建立完整数学模型，并说明模型求解过程。

注意：当前只解决该问题，不分析其他问题；按照数学建模论文"问题分析—模型建立—模型求解"的逻辑展开；重点说明模型构建过程和数学思想，而不是简单堆积公式。

### 1. 问题分析

结合赛题背景分析当前问题，说明该问题需要解决的核心任务、已知数据和条件、需要得到的结果，以及如何将实际问题抽象为数学问题。

输出：
- **【问题分析】** 结合实际背景说明当前问题的研究对象、核心任务以及需要解决的关键问题。
- **【建模目标】** 明确模型需要实现的目标，以及最终需要获得的结果类型。
- **【问题抽象】** 将实际问题转化为数学问题，说明主要变量、影响因素以及变量之间的关系。

### 2. 模型假设

根据实际问题建立合理假设，要求假设符合实际背景，说明每条假设的作用，并避免无依据简化问题。

输出：
- **【模型假设】** 列出模型建立过程中所需的基本假设，并说明假设的合理性和作用。

### 3. 变量与符号定义

|------|------|------|

### 4. 数学模型建立

请按照以下逻辑展开：

1. **模型构建思想**：说明为什么选择该模型、模型如何描述实际问题，以及模型各部分之间的关系。
2. **数学表达**：根据模型特点建立合适的数学表达，给出必要公式，定义相关变量，并解释公式含义。
