# 选题可行性分析报告

## 一、研究题目

**题目**：面向多核神经网络处理器的 DAG 划分与变邻域搜索调度优化

**英文题目**：DAG Partitioning and Variable Neighborhood Search for Multi-core NPU Scheduling

**关键词**：多核调度；DAG 划分；变邻域搜索；NPU；Makespan 最小化

---

## 二、研究空白与选题依据

### 2.1 问题背景

本题来源于 2026 华为杯数学建模竞赛 A 题。目标是在同构多核 NPU 上对 AI 计算图（DAG）进行算子分块与核心分配，根据官方模拟器给出的事实 `(makespan, added_copy_bytes)` 字典序指标优化调度方案。

实际挑战在于：
- DAG 规模从 766 到 38,666 ops，深度跨度 2～459 层，宽度跨度 57～15,921，图结构差异巨大
- 官方评估器（evaluator）是昂贵的黑箱，调用一次耗时 0.2～90 秒，占总用时 95.7%
- 三个问题（无核间同步 / 有核间同步 / 加共享 L2 Cache）分别施加不同的内存/通信约束
- 选手仅提供 block 划分和 core 分配，内部 Spill/Cache 策略完全由官方 Step2/3 决定

### 2.2 现有方法局限

| 方法 | 局限 |
|------|------|
| 贪心分块 + 简单核分配 | 只考虑工作量均衡，忽略通信代价和跨核依赖 |
| List Scheduling (HEFT) | 需要精确的执行时间估计，本题官方评估器不可微、不可内联 |
| 遗传算法 (GA) | 需要大量评估调用，本题评估成本极高 |
| CP-SAT / 整数规划 | DAG 规模大时无法在合理时间求最优解 |

### 2.3 本方案创新点

1. **四族多粒度初解**：平衡、亲和度、关键路径、Pipe 四种互补策略 + grain=4/12/32 三层粒度，覆盖不同图结构特征
2. **VNS 八邻域确定性下降**：核移动、交换、换序、合并、分裂、边界调、联合放置、关键路径移动
3. **候选筛选 + top-K 评估**：便宜估计排序仅将最有价值候选提交昂贵官方评估，最大化每次评估收益
4. **自适应邻域预算**（第三轮新增）：基于历史 gain_per_eval 动态分配邻域搜索预算
5. **细粒度种子恢复**（第三轮新增）：grain=2 变体恢复 v1 优势结构，解决 case_019 regression

## 三、技术可实现性评估

### 3.1 算法成熟度

| 组件 | 理论来源 | 实现状态 |
|------|----------|----------|
| 工作量均衡划分 | 经典 partition 算法 | ✅ 已实现 |
| 亲和度/关键路径 ready-list | HEFT / CPOP 思想 | ✅ 已实现 |
| VNS | Mladenović & Hansen (1997) | ✅ 已实现 8 邻域 |
| 自适应 budget | 基于 statistics 启发 | ✅ 已实现 |
| 候选 cheap ranking | 粗粒度估计器 | ✅ 已实现 |

### 3.2 实验验证

- 第一轮（v1）：6 例 × P1/P2/P3 × N=2/4 = 36 组，平均改善 15.13%
- 第二轮（v2）：36 组，平均改善 18.79%，VNS 增益 2.38%
- 第三轮（v3）：6 例 × P1/P2 × N=2/4 = 24 组 A0/A1/A2 消融，15 例扩展集 A2
- 全部 100 例已完成结构审计，总计 699,118 个操作
- 49 项 pytest 全部通过

### 3.3 计算资源需求

- Windows 10 / Python 3.11+，仅依赖标准库 + matplotlib + PyYAML + pytest
- 单组求解预算 120 秒、36 次评估，开发集六例全跑约 30 分钟
- 无 GPU 需求，无需第三方优化器
