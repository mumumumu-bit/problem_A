# 数学建模竞赛论文学术写作规范体系

## 一、章节架构对比：传统模板 vs 学术论文架构

### 1.1 官方模板 example.tex 的扁平结构
```
摘要
1. 问题重述
   1.1 引言
   1.2 问题的提出
2. 模型的假设
3. 符号说明
4. 问题分析（含建模和求解嵌入其中）
   4.1 问题一分析
   4.2 问题二分析
   4.3 问题三分析
参考文献
附录
```
特点：以「问题编号」为组织线索，建模与求解内容**平摊到各小问中**，无独立实验分析章，无结论章。

### 1.2 我们的方法论流程结构（main.tex）
```
摘要
1. 问题重述
   1.1 问题背景
   1.2 问题描述
   1.3 数据集概述
2. 模型假设与符号说明
3. 模型建立与求解（统一算法框架）
4. 实验分析（消融 + 加速比 + 邻域效率 + 扩展集）
5. 模型评价与结论（优点 + 局限 + 结论）
参考文献
附录
```
特点：以「方法论流程」为组织线索，统一算法框架解决多个场景，实验集中验证。

### 1.3 为什么我们用方法论流程而非传统"逐问平摊"

| 传统模板（逐问展开） | 我们的结构（方法论流程） |
|:-----------------|:---------------------|
| 适合：各问题模型完全独立 | 适合：**统一算法框架**解决三个耦合场景 |
| 结果：P1/P2/P3 的建模方法重复叙述 | 结果：方法叙一次，场景差异集中分析 |
| 论文呈现效果：像"三个小报告的拼合" | 论文呈现效果：像"完整的研究论文" |
| 核心研究内容占比：~55% | 核心研究内容占比：**~75%** |

**选择依据**：附件2未规定章节顺序（见分析报告第七条）。当赛题三个问题共享同一算法框架时，方法论流程结构避免了重复叙述，并让实验对比（消融/加速比/邻域效率/L2对比）在一个章节内形成完整叙事链条。

## 二、各章节学术语言风格与叙事逻辑

### 2.1 摘要 —— 最精炼的「完整压缩」

**叙事模板**：一句话背景 → 凝练方法名称 → 三个具体贡献 → 量化结果 → 创新点列表

**语言要点**：
- 零冗余、零修饰词（删掉所有"良好的""显著的""大幅的"）
- 每个数字必须是确切的实验结果（不是"约18%"而是"17.74%"）
- "本文提出/设计/建立"而不是"本文首先/然后/最后"
- 关键词 4-5 个，覆盖领域 + 方法 + 对象

**我们的摘要检查**：
- ✅ 有建模思路（第23行）
- ✅ 有主要方法四要点（第25行）
- ✅ 有结果与结论（第27行含具体数字）
- ✅ 有三个创新点（第29行）
- ✅ 无英文摘要
- ⚠️ 篇幅偏长（当前约350字），建议是否压缩到一小段视排版而定

### 2.2 问题重述 —— 事实陈述 + 数据锚定

**叙事逻辑**：工业背景 → 架构参数 → 调度挑战 → 赛题来源 → 三个问题的本质差异

**语言要点**：
- 不评价、不解释：纯事实陈述。打通"CPU、NPU、云计算"就要在第一个自然段引出入胜负
- 所有硬件参数必须精确：L1=524,288 bytes 而不是"约520KB"
- 「三耦合决策」一次到位：切图（规模/通信）、核心分配（负载/跨核量）、核内顺序（等待/溢出）
- 数据分布用表格呈现（表1，100例统计），让读者形成量化直觉

**标识性动词**：拥有、包含、记为、给定、返回、构成
**避免的动词**：展现、体现、发挥、具有

### 2.3 模型假设 —— 工具性声明

每条假设 = 假设内容 + 为什么要这样假设 + 违反会怎样

**模板**：
```
假设N：XXX。作用：YYY。放宽此假设将导致 ZZZ。
```
不宜写成"我们做以下假设"的列表。示例中的两行"模型假设"即标注了本假设对建模的必要性，然后立即解释本假设放宽的后果——这就完成了学术叙事。

### 2.4 符号说明 —— 聚类而非列表

不要逐行罗列。按功能聚类：
- 图结构符号（G, T, O, E）
- 规模与参数（N, n, c_o, s_t）
- 决策变量（K, x, p, π_j）
- 评估指标（T_ms, C_add）
- 算法参数（N_k, B, g）

每个符号 = 符号 + 中文含义 + 物理单位

### 2.5 模型建立与求解 —— 最重的章节

**叙事逻辑**：
1. **算法框架总览**（一段）：三个阶段是什么，它们的输入输出关系
2. **初解生成**：coarsening 数学定义 → 四种策略分别一张图一句话（差异化特征）→ 核心分配（HEFT风格）
3. **自适应VNS**：邻域表 → top-K 数学逻辑 → 自适应公式 → 预算与早停条件是硬数字（36, 8, 120）
4. **fine-grain恢复**（单独小节）：v1→v2→v3 的时间线，拿具体数字做论证

**语言要点**：
- 每个算法的引出 = "为什么需要这一步" + "这一步的核心操作是什么"
- 数学公式只写核心逻辑（gain_per_eval, gain_per_sec），不写满屏推导
- 符号与符号说明表保持严格一致

### 2.6 实验分析 —— 数字驱动叙述

**必须包含的元素**：
1. 实验设置（环境、种子、数据集、评估指标）
2. 消融结构表（A0/A1/A2 差异仅一列）
3. 主结果图 + 逐例明细表 + 关键发现（bullet points）
4. 加速比图 + 具体数字解读
5. 邻域效率表 + "阶梯分布"定性概括
6. 扩展集规模分析
7. 正确性声明（pytest, CLI复核）

**图表规范**：
- 表标题在上方，图标题在下方
- 每表/图需在正文中至少引用一次（\ref）
- 数字列右对齐，文字列左对齐
- 三线表（toprule / midrule / bottomrule）
- 图用矢量PDF（DPI ≥ 300）

**数字叙事模板**：
> "表X显示了...。N1（21.2%有效率）和N2（18.0%）承担了绝大部分优化动力（73/96次改善）。N3在同一数据集上消耗了78次评估（占总调用的13.3%）却没有产生任何真实改善。"

注意：先数据 → 再对比 → 再定性概括。不做"我们认为"的主观评价。

### 2.7 模型评价与结论

**优点**：每个优点 = 特性 + 为什么有价值（不是贴金，是技术论证）
**局限性**：每个局限 = 具体问题 + 为什么当前方法解决不了 + 可能的方向
**结论**：一句话总框架 + 核心数字 + 适用性声明 + 未来方向

**避免万能句**：
- ❌"具有重要的理论意义和实践价值"
- ❌"未来将进一步研究"
- ✅"P1的N=4加速比为2.42，P2的N=4加速比为2.89"
- ✅"该框架为后续引入CP-SAT精确校验和动态在线调度提供架构基础"

## 三、专业术语运用规范

### 3.1 统一命名体系
全文只能有一个名称体系，不能混用中英文、缩写和全称。

| 首次出现 | 后续引用 |
|:-------|:-------|
| 多核神经网络处理器（NPU） | NPU |
| 变邻域搜索（Variable Neighborhood Search, VNS） | VNS |
| 有向无环计算图（DAG） | DAG |
| 统一缓冲区（Unified Buffer, UB） | UB |
| Makespan（总执行时间） | Makespan |

### 3.2 数学符号一致性
- 正文中出现的所有数学符号必须出现在「符号说明」表中
- 公式格式：\$T_{\\text{ms}}\$ 而非 \$T_ms\$
- 集合：\$\mathcal{N}_k\$ 而非 \$N_k\$
- 上下标：有意义的用 `\text`，变量用斜体

### 3.3 数值精度约定
- Makespan: 整数（cycles，不保留小数）
- 加速比: 两位小数（2.42）
- 改善率: 两位小数（17.74\%）
- 评估耗时: 一位小数（378.1秒）
- 数据量: 整数，超过4位加千分位（3,171,548）

## 四、叙事节奏控制

### 4.1 段落长度差异化
- 最短段（过渡段）：1-2句，30字以内
- 标准叙事段：3-5句，80-150字
- 技术详述段（含公式/表格）：5-8句，150-250字

**反模式**：连续3段以上长度高度相似（→ AI痕迹）

### 4.2 主语变换
避免全文同一主语开头（"本文..." → "我们..." → "该算法..." → "实验..."交替使用）

### 4.3 转折词约束
每节转折/递进词不超过段落数的30%。"此外""另外"这类词每出现一次就要检查是否可删。

## 五、图表制作终极规范

### 5.1 表格
```
\caption{在上方}
\small
\label{自动编号}
三线表: \toprule / \midrule / \bottomrule
数值列右对齐(r)，文字列左对齐(l)
```

### 5.2 图片
```
\caption{在下方}
宽度: 单栏0.48\textwidth，双图并列
格式: PDF矢量优先
\includegraphics[width=\textwidth]{figures/xxx.pdf}
```

### 5.3 编号体系
- 表：Tab.1, Tab.2...（`\label{tab:xxx}`）
- 图：Fig.1, Fig.2...（`\label{fig:xxx}`）
- 公式：Eq.(1), Eq.(2)...（`\begin{equation}`自动编号）
- 引用时用`\ref`，不手写编号

## 六、论文写作自检清单（终稿前逐项核对）

### 字号与格式
- [ ] 无"随着...发展"式开头
- [ ] 无"本文首先/其次/然后/最后"式结构预告
- [ ] 所有"显著/良好/大幅/重要"已替换为具体数字
- [ ] 有 ≥ 2 处失败/退化讨论
- [ ] 模糊修饰词 = 0（全程可量化）

### 数据与图表
- [ ] 所有表格三线表 + 标题在上 + \small
- [ ] 所有图片矢量PDF + 标题在下 + \ref引用
- [ ] 每张图表 ≥ 3 句正文解读
- [ ] 数据与正文描述严格一致（例：Makespan数字无偏差）

### 引用与规范
- [ ] 参考文献按正文引用顺序排列
- [ ] 引用格式符合附件2第7条
- [ ] AI工具声明在附录中标明
- [ ] 无页眉，无身份信息泄露

### 页面与篇幅
- [ ] 摘要不超过两页
- [ ] 正文章节间有合理留白（不拥挤）
- [ ] 图表不跨页断裂
- [ ] 参考文献从新页开始
